# Локальная 0.3.8-v125

1. В «Состоянии устройства» подписи и значения собраны рядом, расстояние
   между ними — 10 dp. Пары выровнены по центру, длинные значения переносятся.
2. Из терминала VPS убрана отдельная плашка с надписью «VPS» и значком;
   остались заголовок, описание и управление соединением.
3. Пароль Wake-on-LAN автоматически сохраняется после успешной команды,
   восстанавливается после проверки сессии и прав. Используется AES-GCM
   с ключом Android Keystore, отдельная запись для Hub, аккаунта и роутера.
   Неудачный запрос не заменяет рабочий пароль. Есть кнопка забывания пароля.
4. В настройках появился пункт «Защита приложения». Включение требует
   подтверждения Android. При открытии и возвращении из фона запрашиваются
   PIN, графический ключ или пароль телефона; при настроенной биометрии
   доступен отпечаток. Можно отключить биометрию, заблокировать приложение
   немедленно или отключить защиту после подтверждения.
5. В «О приложении» сначала отображается золотая корона по центру, затем
   текст о приложении и версиях.
6. На веб-панели уменьшен текст «Все роутеры на связи / Есть роутеры без связи».
7. На ПК индикатор и значения диска выровнены по вертикальному центру блока;
   эта правка не применяется к iOS.
8. Стрелки перестановки карточек уменьшены в Android, на ПК и iOS.

APK: `artifacts/android/OWRT-Hub-Android-0.3.8-v125.apk`, versionCode 18.
Размер: 2 023 117 байт. Подпись совпадает с 0.3.7.
SHA256: `dbdd7fb1ec73c40aaab3ee3886a19949f8fdd6fdc787a8c840c64cca0732f564`.

Установка поверх текущей через ADB, PowerShell Windows 11:

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.8-v125.apk')
```

Возврат к предыдущей локальной APK с той же подписью:

```powershell
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.7-v125.apk')
```

Старая версия не поддерживает новую блокировку приложения; при возврате
в 0.3.8 сохранённая настройка защиты продолжает действовать.

Защита использует уже настроенную блокировку телефона. Отдельный PIN или
пароль Hub не создаются и в приложении не хранятся. На Android 8 используется
системный FingerprintManager, на Android 9+ — BiometricPrompt; всегда доступен
переход к системному подтверждению PIN/ключом/паролем. Если защита включена,
внутренние экраны закрыты от снимков и системного предпросмотра задач.

Серверная часть, установка и проверки:
[ANDROID_LOCK_LAYOUT.md](../docs/ANDROID_LOCK_LAYOUT.md).

Проверены 25 сценариев интерфейса Android 15, узкий экран со шрифтом 130%,
отдельные сценарии Wake-on-LAN и системного PIN, запуск в новом процессе,
отмена и подтверждение отключения защиты. Сборка, lint и подпись — без ошибок.
Физический датчик отпечатка на телефоне пользователь проверяет отдельно.
