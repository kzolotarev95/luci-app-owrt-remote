# Android 0.3.0-v125 — локальная переработка интерфейса

Нативный интерфейс приложения приведён к стилю ПК-панели OWRT Hub v125.
Серверный API и протокол агента для этого изменения менять не требуется.

## Интерфейс

- Графитовые фон, карточки и поля, лаймовый основной акцент, золотистые акценты
  поддержки и фотографий, единая типографика Inter.
- Новое меню с разделами «Рабочее пространство», «Управление», «Настройки» и
  «Сообщество». Раскрытие разделов запоминается. Нижние вкладки дают быстрый
  доступ к обзору, роутерам и настройкам.
- Компактный дашборд: четыре счётчика роутеров, ЦП и ОЗУ VPS, карта подключений,
  график доступности за 24 часа и отдельный баннер диска с заполнением и объёмами.
- Карта использует полный доступный пользователю список, независимо от фильтров
  экрана роутеров. Первые семь устройств, «Показать все» / «Скрыть все», нажатие
  на устройство открывает его карточку. Анимация связей отключается вне видимой
  области, при экономии батареи и в облегчённом режиме.
- Карточки с фотографией конкретной модели, состоянием Xray, памятью,
  температурой и заметкой. Детальная карточка и кнопки управления сохранены.
- 87 WebP-фотографий для 99 записей моделей включены в APK. Сопоставление по
  модели из агента; неизвестная модель получает нейтральный значок. Источники,
  сведения о моделях и контрольные суммы: `vps/router-model-photos/catalog.json`.
- Единый стиль входа, настроек, Xray, терминалов, WoL, заметок, обновлений,
  резервных копий и оболочки встроенного браузера инструментов.
- Графитовая и зимняя темы, режим «Для слабых устройств» без эффектов, эффекты
  «Потоки» и «Снег». Сохранены скрытый адрес Hub и зашифрованное хранилище сессии.
- Обновление данных изменяет существующие виджеты и сохраняет фокус, поиск,
  раскрытие карты и прокрутку. Видимость статистики переживает перезапуск.

LuCI и Tachyon сохраняют собственные веб-интерфейсы во встроенном браузере.
Оплата и остальные внешние ссылки открываются по явному нажатию.

## Локальная сборка и установка

Из корня проекта в PowerShell Windows 11:

```powershell
python .\android\build-support\sync-router-photos.py --check
& .\android\build-support\build.ps1
```

Результат: `android/app/build/outputs/apk/debug/app-debug.apk`.
Имя пакета `ru.owrthub.app` и прежний ключ `.signing/debug.keystore` сохранены.
Установите APK поверх текущей версии, без удаления приложения.

С USB-отладкой и единственным подключённым телефоном:

```powershell
$Repo = 'C:\Users\k.zolotarev95\Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'android\app\build\outputs\apk\debug\app-debug.apk')
# Откат локальной debug-сборки на предыдущую APK с тем же ключом:
& $Adb -d install -r -d (Join-Path $Repo 'android\apk\OWRT-Hub-Android-0.2.6-v124.apk')
```

Откат не восстанавливает предыдущие настройки оформления. Сессия хранится в
прежнем формате. Перед публикацией APK нужны проверка на телефоне пользователя
и отдельная команда на выпуск; локальная сборка не является релизом Google Play.
