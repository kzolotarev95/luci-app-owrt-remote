# Локальная 0.3.7-v125

- В карточках роутеров появились стрелки «раньше/позже» и значок переноса.
  Удерживание значка запускает системное перетаскивание Android.
- Порядок сохраняется на Hub для текущего аккаунта и восстанавливается
  после опроса, перехода между экранами и повторного открытия приложения.
  ПК, iOS и Android используют один порядок на одном Hub под одним логином.
- В общем списке перестановка работает внутри группы, в фильтрах
  «Онлайн/Офлайн» — по показанному плоскому списку. Настройки групп не меняются.
- Во время перетаскивания опрос откладывается. Крайние стрелки отключены;
  ошибка сохранения показывается явно. Для старой серверной сборки выводится
  предложение обновить Hub.
- Сохранены все исправления выравнивания, диска, входа и банков из 0.3.6.

APK: `artifacts/android/OWRT-Hub-Android-0.3.7-v125.apk`, versionCode 17.
Размер: 2 005 322 байт. Подпись совпадает с 0.3.6.
SHA256: `20ba505ec1e0ab3ab7ead41b251594b20bdb355da62a2e28cdbdfc983ae7b6f7`.

Установка через ADB на подключённый телефон, PowerShell Windows 11:

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.7-v125.apk')
# Откат на предыдущую сохранённую тестовую APK:
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.6-v125.apk')
```

Установка и откат VPS: [ROUTER_CARD_ORDER.md](../docs/ROUTER_CARD_ORDER.md).

Проверены сборка и lint без ошибок, полный набор из 25 сценариев в эмуляторе
Android 15. Отдельно проверено новое управление порядком на обычном экране
и на экране 320 dp со шрифтом 130%: стрелки, сохранение после опроса и
перезапуска Activity, удержание значка, настоящий системный Drag and Drop
и автопрокрутка к целевой карточке. Реальный телефон проверяет пользователь.
