# OWRT Hub для Android

[Скачать APK 0.2.4-v123](https://github.com/kzolotarev95/luci-app-owrt-remote/raw/refs/heads/main/android/apk/OWRT-Hub-Android-0.2.4-v123.apk)

Android 8.0 и новее. Это нативное приложение для подключения к своему VPS Hub,
а не пакет OpenWrt для установки на роутер. Версия Hub остаётся v123.

Установите APK поверх предыдущей нативной версии: имя пакета, подпись и формат
сохранённой сессии совместимы. Приложение не содержит заранее заданного сервера:
укажите свой HTTPS-адрес и войдите с учётной записью Hub.

Для новых функций заметок обновите VPS через «Обновление панели».
Текущий исходник содержит мобильный API ревизии 4; роутер для этого обновлять
не нужно. Для ручной установки и отката см. [инструкцию](../CHANGES-0.2.4.md).

APK — тестовая сборка, подписанная прежним локальным debug-ключом;
она не является выпуском Google Play. Ключ подписи в репозиторий не включён.
SHA256 файла указан в [SHA256SUMS](SHA256SUMS). Проверка в PowerShell:

```powershell
Get-FileHash .\OWRT-Hub-Android-0.2.4-v123.apk -Algorithm SHA256
```

Исправления: [0.2.2](../CHANGES-0.2.2.md), [0.2.3](../CHANGES-0.2.3.md),
[0.2.4](../CHANGES-0.2.4.md). Сборка, права и ограничения — в [README Android](../README.md).
