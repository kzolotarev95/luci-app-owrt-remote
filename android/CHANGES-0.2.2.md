# Android 0.2.2-v123 — исправления по замечаниям

Все изменения подготовлены локально. Версия Hub и агента остаётся v123.

1. Иконка: круглый фон с прозрачными углами вместо квадратной подложки. Системная
   маска значков зависит от launcher телефона.
2. Подключение: поле адреса пустое, личный домен не подставляется. Блок
   «Нативное приложение» удалён. Существующая сессия сохраняется при обновлении.
3. Адрес в шапке скрыт. Кнопка с глазом показывает/скрывает домен и порт;
   при открытии другого экрана адрес снова скрыт. Это также действует для VPS-консоли.
4. При первом успешном входе владельца предлагается включить уведомления.
   На Android 13+ запрашивается системное разрешение. Переключение доступно
   в «Настройки → Уведомления». Приложение держит один последовательный HTTPS
   long-poll к Hub, выводит системные уведомления и хранит курсор событий отдельно
   для сервера/аккаунта. Подключение видно в постоянном уведомлении с кнопкой
   выключения; при ошибке действует задержка переподключения до 60 секунд.
   Сервис не использует Firebase/FCM. После force-stop, перезагрузки телефона
   или остановки Android нужно открыть приложение. Работа при глубоком
   энергосбережении зависит от устройства. Уведомления пока доступны владельцу Hub.
5. Терминалы: кнопка отправки не отключается на чтении вывода; ввод во время
   чтения ставится в ограниченную очередь. Нет автоматического повтора команды
   после ошибки сети. Пустые ответы не перерисовывают вывод; исправлен перенос
   CR/LF между частями ответа. Вывод прокручивается отдельно, ввод остаётся
   доступным. При просмотре истории автопрокрутка отключается.
   SSH-пароль root можно сохранить по переключателю: AES-GCM/Android Keystore,
   отдельно для HTTPS-адреса, пользователя Hub и роутера. Пароль отправляется
   один раз только на запрос SSH; при неверном пароле повторный ввод ручной.
   «Забыть пароль этого роутера» удаляет запись. Это не сохраняет пароль Hub.
   Консоли остаются построчными, без полной эмуляции VT/xterm.
6. Обзор/карточки обновляют значения каждые 5 секунд, сохраняя окно, элементы,
   фокус и прокрутку. Значения отражают последние данные сервера; Heartbeat самого
   роутера может приходить реже. Фоновый опрос не мигает общей полосой загрузки
   и не блокирует кнопки. Действие, нажатое во время чтения, выполняется после него.
7. Добавление роутера: Hub предлагает свободные ID, Web/SSH-порты, адрес VPS,
   роль и группы. Сервер учитывает также занятые Tachyon-порты, не раскрывает
   UUID/ключи и проверяет право добавления. Старый модуль API не может заменить
   новый при самообновлении Hub: до публикации новая локальная сборка пропускает
   несовместимый источник GitHub. После создания доступна кнопка
   «Получить настройки OpenWrt»: копирование и сохранение готовых команд .sh.
   Установка агента выполняется на выбранном роутере этими командами; приложение
   не запускает установщик на случайном устройстве автоматически.

## Установка на ваш VPS

Нужна для пункта 7; остальные исправления относятся к APK. PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-android-feedback.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Скрипт сохраняет `/root/owrt-remote-backup-before-android-feedback-022-v123`,
проверяет кандидата, перезапускает Hub и проверяет ревизию/API. Данные роутеров
и настройки аккаунтов не заменяются. Пароль вводится в SSH, не сохраняется скриптом.

Откат серверной части:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Установите `OWRT-Hub-Android-0.2.2-v123.apk` поверх 0.2.1. Подпись, имя пакета
и формат сессии сохранены. Для отката APK с USB-отладкой:

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.2.1-v123.apk')
```

Откат приложения не выключает установленный API. На VPS и физическом телефоне
эта локальная сборка агентом не устанавливалась; нужен пользовательский прогон.

## Проверки

Android 15/API35, изолированный стенд без реальных команд и доступа к роутерам:
системное уведомление Android, скрытие адреса, сохранение окна при обновлении,
создание роутера и конфигурация, SSH-автоввод, шифрование/удаление пароля,
обе консоли, права, 2FA и передача файлов. Основной прогон дополнительно
проверяет обычный и увеличенный шрифт. Числа и SHA256 конечной APK находятся
в локальном `artifacts/android/validation-native-0.2.2.json`.
