# Локальная 0.3.6-v125

- Заголовки разделов Android выровнены по центру. У карты подключений,
  доступности и диска симметричное место для заголовка: кнопка скрытия
  больше не сдвигает его влево. На узком экране с крупным шрифтом кнопка
  переносится под заголовок. Подписи дашборда расположены под заголовком.
- В терминале VPS убраны глаз и строка «Адрес скрыт». Управление видимостью
  адреса на основных экранах осталось доступным.
- Значения диска собраны в компактную группу по центру: колонки занимают
  ширину содержимого, расстояние между подписью и значением — 4 dp.
- Пять логотипов банков в поддержке разработки расположены в один ряд.
  Подписи остаются однострочными и подстраиваются под ширину колонки.
- Карточки статистики дашборда стали компактнее: базовая высота 64 dp,
  уменьшены отступы и размер чисел. Системное увеличение шрифта учитывается.
- На входе один логотип по центру, под ним «С возвращением». Верхняя
  дублирующая шапка OWRT Hub с адресом и глазом убрана с экрана входа.

APK: `artifacts/android/OWRT-Hub-Android-0.3.6-v125.apk`, versionCode 16.
Размер 1 996 768 байт. Подпись совпадает с 0.3.5; можно установить поверх неё.

SHA256: `372a689e678ada6508aa60483d4d97ea94245f86cd8bfdb7637805ea0455ab60`.

Установка на подключённый физический телефон через ADB, PowerShell Windows 11:

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.6-v125.apk')
# Возврат на сохранённую предыдущую тестовую APK:
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.5-v125.apk')
```

APK локальная, опубликованный выпуск и версия интерфейса Hub не изменены.
Связанные исправления iOS/ПК и команды для VPS:
[DASHBOARD_MOBILE_ALIGNMENT.md](../docs/DASHBOARD_MOBILE_ALIGNMENT.md).

Проверены сборка, lint без ошибок и по 23 сценария на обычном Android-экране
и узком экране 320 dp с системным шрифтом 130%. Использован эмулятор Android 15;
физический телефон пользователь проверяет отдельно.
