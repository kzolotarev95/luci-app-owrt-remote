# Android 0.2.4-v123

Локальная тестовая сборка по четырём замечаниям. Версия панели и агента — v123.

1. **Карточка роутера.** Значок устройства, имя и статус Heartbeat расположены
   по центру. В «Состояние устройства» подписи и значения занимают равные
   колонки с центрированием; значения больше не прижимаются к правому краю.
   Проверены карточки онлайн и офлайн.
2. **Удаление заметок.** В каждой записи у владельца Hub есть «Удалить заметку».
   После подтверждения удаляются выбранная запись и прикреплённые к ней фото.
   Остальная история и черновик сохраняются. Отмена не меняет заметки.
   Сервер повторно проверяет сессию, владельца и CSRF. Права соответствуют
   веб-панели: делегированный пользователь не может удалять историю.
   Исправлены меняющиеся ID старых записей без сохранённого идентификатора.
3. **Настройки.** Уменьшены «Ваш Hub», имя пользователя, роль и внутренние
   отступы карточки. Над именем владельца расположена небольшая золотая корона.
4. **Вход.** Адрес, порт, логин, пароль, код 2FA, подсказки и ввод капчи
   центрированы. Число капчи выровнено относительно всей карточки, с учётом
   кнопки обновления справа. Поле 2FA сохраняет условное отображение.

## Установка локальной версии

Для удаления заметок нужен API ревизии 4 на VPS. PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-android-note-delete.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Резервная копия: `/root/owrt-remote-backup-before-android-note-delete-024-v123`.
Скрипт проверяет кандидаты и контрольные суммы, перезапускает Hub и проверяет
health и защиту API. На старом API удаление скрыто; новые заметки читаются как прежде.

Откат VPS из той же копии:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Установите `OWRT-Hub-Android-0.2.4-v123.apk` поверх 0.2.3 на телефоне.
Подпись, пакет и формат зашифрованной сессии сохранены. Роутер обновлять не нужно.
Откат APK через USB с включённой отладкой:

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.2.3-v123.apk')
```

## Проверки

APK собрана локально. Android Lint: 0 ошибок. Серверные HTTP-тесты проверяют
удаление выбранной записи и фото, сохранность остальных записей, старый формат
заметок, отсутствие прав, CSRF и повторное удаление. На изолированном Android
15/API 35 проверены подтверждение и отмена удаления, сохранение черновика,
прикрепление/отображение фото, вход, консоли и остальные основные функции.
Результаты, снимки и SHA256 APK находятся в локальном `artifacts/android/`.

На физическом телефоне и боевом VPS эта сборка агентом не устанавливалась.
Коммит, push и выпуск пакетов не выполнялись.
