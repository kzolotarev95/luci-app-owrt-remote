# Android 0.2.6-v124 — тестовая сборка

- В настройках владельца добавлен «Xray на VPS»: пересборка и применение Xray CFG,
  перезапуск сервиса. Действия подтверждаются отдельно и используют существующий API VPS.
- В «Настройки Xray» роутера фоновый опрос не показывает индикатор загрузки
  и не переключает доступность всех кнопок. При работающем Xray кнопка запуска
  отключена в приложении и веб-панели. Неизменившаяся история веб-панели не пересоздаётся.
- Подпись «Сессия зашифрована в Android» выровнена по центру.
- Выборочное обновление/перезапуск роутеров: общий список, галочки, выбор всех/онлайн,
  общий пароль, отдельный пароль или ключ для каждого устройства. Старый VPS без
  поддержки выбора не получает команду на все роутеры вместо выбранных.
- Добавлены нативные фоновые эффекты «Потоки» и «Снег» для экранов приложения.
  Выбор сохраняется. При скрытом окне/переходе в фон таймер останавливается;
  при энергосбережении и выключенных системных анимациях рисунок статичен.
- Wake-on-LAN использует список устройств из того же SSH-поиска, что и веб-панель:
  устройство, количество, пароль, «Обновить» и «Разбудить». Передаётся MAC/интерфейс
  выбранного устройства. Пароль не сохраняется на диск, очищается при уходе и отправке
  пакета; после поиска остаётся в текущем поле для последующего пробуждения.

Тестовая APK подписана прежним локальным debug-ключом, устанавливается поверх 0.2.5.
Приложение не обновляет VPS самостоятельно при установке APK.

Для всех функций обновите VPS через «Обновление панели» из текущего main.
Также доступна установка и откат из локального checkout:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-android-tools-fix.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
# Откат Hub и mobile_api.py из отдельной резервной копии:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-android-tools-v124`.
Установка перезапускает Hub; дождитесь завершения активных очередей и терминалов.
Для выборочного обновления и Wake-on-LAN нужен рабочий SSH-туннель роутера.
Код агента роутера для этих функций менять не требуется.

Проверено локально: сборка APK/test APK и Lint без ошибок; 28 smoke-сценариев
на Android 15/API 35; 176 проверок URL и 67 проверок API-клиента, 10 тестов
тестового сервера. Веб-кнопка запуска Xray проверена на 1280/320/390/844 px.
Проверки используют изолированный сервер; реальные VPS и роутеры не изменялись.
