# Android 0.3.2-v125 — карточки, карта и меню

Локальная тестовая сборка, `versionCode=12`.

- Из обзора убран дублирующий список карточек и кнопка «Все роутеры». Карточки
  находятся во вкладке «Роутеры»; в обзоре сохранены статистика, карта, график
  доступности и диск.
- Xray, температура и память размещены непосредственно рядом с фотографией
  устройства. Фото и показатели собраны в одну компактную группу по центру.
- В меню добавлены векторные значки разделам и всем пунктам, включая сообщество,
  NetHaven, поддержку и выход. Сохранены права доступа и запоминание разделов.
- Карта использовала перерисовку раз в 80 мс (около 12,5 кадров/с) и условие
  `i < 7`, выключавшее движение на следующих строках. Теперь линии анимируются
  отдельным View по кадрам экрана; фотографии и текст не перерисовываются на
  каждом кадре. Геометрия и длины путей рассчитываются при изменении разметки,
  общая магистраль рисуется один раз.
- Движение работает для всех видимых онлайн-подключений, в том числе после
  «Показать все», прокрутки и обновления данных. За пределами экрана и после
  ухода с обзора цикл останавливается. Учитываются облегчённый режим,
  системное отключение анимаций и экономия батареи.

Проверено в эмуляторе Android 15: 17 сценариев, в том числе движение видимого
подключения за пределами первых семи, изменение пикселей на линии между
предъявленными кадрами, сохранение раскрытия после опроса и прекращение кадров
после ухода с обзора. Проверены обычный экран и узкий экран со шрифтом 130%.
`assembleDebug`, `assembleDebugAndroidTest`, `lintDebug` прошли; ошибок Lint нет.
Снимки экрана проверены отдельно для подписей рядом с фото и значков меню.
Проверка на реальном телефоне ещё предстоит.

## Установка и откат

APK устанавливается поверх предыдущей версии с тем же ключом. VPS обновлять для
этого исправления не требуется. Из PowerShell Windows 11, для одного подключённого
по USB телефона с USB-отладкой:

```powershell
$Repo = 'C:\Users\k.zolotarev95\Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.2-v125.apk')
# Откат на сохранённую предыдущую APK:
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.1-v125.apk')
```

Сборка из исходников: `& .\android\build-support\build.ps1`.
