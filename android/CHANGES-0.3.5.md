# Локальная 0.3.5-v125

- В доступности роутеров появились периоды 6 ч, 12 ч и 24 ч. Меняется реальный
  интервал графика, точки за его пределами отбрасываются. Выбор сохраняется
  после опроса статусов, переходов и повторного открытия приложения.
- Полноэкранный режим на всех экранах, включая вход, настройки, роутер и
  встроенный браузер: строка времени/сети и системная навигация скрыты.
  Системный жест временно возвращает их. Android может один раз показать
  собственную подсказку о полноэкранном режиме.

APK: `artifacts/android/OWRT-Hub-Android-0.3.5-v125.apk`, versionCode 15.
Размер 1 797 685 байт. Подпись совпадает с 0.3.4; установка поверх неё.

SHA256: `e8493f4518b97e4818802803c7501cc90e6808c0b64c5f33838b12521cce7c7a`.

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.5-v125.apk')
# Возврат к сохранённой 0.3.4 с тем же ключом:
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.4-v125.apk')
```

Проверены сборка, lint без ошибок и 20 сценариев в эмуляторе Android 15:
полноэкранный вход, интервалы реального ChartView, обновление без пересоздания,
сохранение после перезапуска, анимация карты, раскрытие всех роутеров, скрытие
блоков, навигация и поворот экрана. Проверка на реальном телефоне предстоит.
