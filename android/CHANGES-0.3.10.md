# Локальная 0.3.10-v125

1. Flash в «Состоянии устройства» отображается в одну строку. Убрано
   ограничение ширины, которое переносило даже помещающиеся значения.
   Строка использует доступную ширину карточки; при необходимости размер
   текста подбирается в небольшом диапазоне. Центрирование пары сохранено.
2. Из верхних панелей приложения удалены кнопки со стрелкой назад:
   карточка роутера, инструменты, настройки, резервные копии и встроенный
   браузер. Системная кнопка/жест Android продолжает управлять возвратом.
3. Из шапок убрана строка «Адрес скрыт», раскрытие адреса глазком и сам
   глазок адреса. Встроенный браузер также не показывает домен/IP в шапке.
   Адрес по-прежнему доступен в явном разделе «Подключение».

Только Android. Изменения VPS, агента роутера и API не требуются.
Новая APK устанавливается поверх предыдущих локальных сборок с той же подписью.
