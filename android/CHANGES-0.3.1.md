# Android 0.3.1-v125 — выравнивание по центру

Локальная тестовая сборка, `versionCode=11`.

- В «Обзоре» и «Роутерах» фотография теперь находится над названием и ID,
  на одной центральной оси с остальными данными карточки.
- В баннере «Диск VPS» заголовок и круговой индикатор расположены по центру.
  Свободное, занятое место и общий объём показаны под ним в трёх равных колонках.
- Заголовки разделов настроек, значки, названия и описания пунктов центрированы.
  Такое же оформление применяется к выбору дизайна и эффектов.

Для установки используйте новую APK поверх Android 0.3.0, с прежним ключом
подписи. API VPS для этого изменения менять не требуется.

Проверено локально в эмуляторе Android 15: сборка, Lint без ошибок и 12 сценариев
`NativeRedesignInstrumentation`, включая поворот экрана и обновление данных.
Фактическое выравнивание карточек, баннера диска и настроек проверено по снимкам
экрана. Приложение на реальном телефоне пользователь проверяет отдельно.

## Установка и откат через PowerShell Windows 11

Для единственного подключённого по USB телефона с включённой USB-отладкой:

```powershell
$Repo = 'C:\Users\k.zolotarev95\Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.1-v125.apk')
# Откат на сохранённую предыдущую тестовую APK:
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.3.0-v125.apk')
```

Сборка из исходников: `& .\android\build-support\build.ps1`.
