# Android 0.2.3-v123

Исправления подготовлены локально по пяти замечаниям. Панель и агент остаются v123.

1. **SSH и VPS-консоль.** До нажатия «Подключить SSH» / «Открыть терминал VPS»
   скрыты вывод, ввод команд, поля пароля и кнопки терминала. После нажатия
   появляется рабочая область; после закрытия снова остаётся подключение.
   Для первого входа SSH пароль можно ввести после открытия и нажать
   «Отправить пароль SSH». Сохранённый пароль отвечает на запрос автоматически.
2. **Обновление Hub.** Проверка совместимого исходника больше не отвергает
   его из-за более старой ревизии мобильного helper. Обновлятор сохраняет
   новый встроенный API и политику его сохранения, проверяет полученный файл
   и предлагает именно его SHA256 для подтверждения. Worker сверяет тот же
   SHA256, сохраняет предыдущие файлы, перезапускает Hub и проверяет health;
   при неудаче выполняется откат. Исходник без поддержки нативного API,
   повреждённый payload или более старая версия Hub по-прежнему отклоняются.
   В приложении есть подпись «Доступно обновление Hub v…», подтверждение
   установки и результат. Раздел настроек также показывает доступную версию.
   Это не автоматическая установка: требуется нажатие и подтверждение.
3. **Поддержать разработку.** Открывается внутренний баннер с текстом,
   основной и резервной ссылками, логотипами СБП, Сбера, Альфа-Банка, ВТБ
   и Т-Банка. На внешнюю платёжную страницу переходят только по ссылке внутри.
4. **Оформление.** Общий размер нативного текста уменьшен примерно на 14%,
   кнопки — до 14sp, поля — до 14sp. Счётчики, значения, заголовки и обычный
   текст выровнены по центру. Команды и вывод консоли сохраняют выравнивание
   слева; многострочные поля сохраняют удобство ввода. Системное увеличение
   шрифта Android не отключено.
5. **Заметки и фото.** В карточках обзора/списка появились количество и превью
   заметок. Экран заметок показывает изображения; нажатие открывает увеличенный
   просмотр. Через системный выбор документов можно добавить до четырёх фото.
   Для передачи приложение уменьшает их до 1600px и JPEG (до 500 КиБ на фото).
   Можно сохранить запись только с фото, без текста. Прежние записи и вложения
   сохраняются. История показывается порциями по 20 записей, фото загружаются
   по мере появления на экране. Сервер проверяет сессию, права, CSRF, формат,
   количество и общий размер. Старый API не принимает фото молча: приложение
   попросит сначала обновить серверную часть.

## Установка для теста

Для исправления обновлятора и изображений нужен новый API на VPS. PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-android-notes-ui.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Скрипт использует текущие локальные `hub.py` и `mobile_api.py`, проверяет payload,
создаёт отдельную резервную копию, перезапускает Hub и сверяет ревизию/API.
Резервная копия: `/root/owrt-remote-backup-before-android-notes-023-v123`.

Откат VPS:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Затем установите `OWRT-Hub-Android-0.2.3-v123.apk` поверх 0.2.2. Подпись и сессия
сохранены. Откат APK через USB с разрешённой отладкой:

```powershell
$Repo = Join-Path $env:USERPROFILE 'Documents\openwrt overlay'
$Adb = Join-Path $Repo '.test-output\android-build-tools\sdk\platform-tools\adb.exe'
& $Adb -d install -r -d (Join-Path $Repo 'artifacts\android\OWRT-Hub-Android-0.2.2-v123.apk')
```

## Проверки и границы

Используется Android 15/API35 и изолированный HTTP-стенд. Передача изображения
проверяется фактическими байтами через ContentProvider/системный выбор документа,
HTTP-запись и отображение в ImageView. Отдельные Python HTTP-тесты проверяют
хранение/чтение фото и права. Тест обновления устанавливает подтверждённый
кандидат во временный каталог; systemd и health заменены контролируемыми ответами.
Также проверена подготовка кандидата из исходника реально опубликованного `main`.

На боевом VPS и физическом телефоне эта сборка агентом не устанавливалась.
Не проверены все модели Android и все версии загрузчиков документов. Консоль
остаётся построчной; полноценная эмуляция VT/xterm в эту задачу не входит.
Результаты и SHA256 итоговой APK сохранены в локальном `artifacts/android/`.
