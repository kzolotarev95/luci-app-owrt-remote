# Локальная 0.3.11-v125

- Общий малиновый акцент заменён на ярко-красный `#ff3030` / RGB(255,48,48).
- Новый цвет применяется к Offline, ошибкам, опасным действиям, графикам,
  уведомлениям и прочим компонентам, использующим RED.
- Конечный цвет градиента имён тоже заменён: голубой → фиолетовый → красный.
- Зимняя тема использует тот же красный. Прозрачность заливок, рамок и
  неактивных состояний сохраняется.
- Убрана отдельная малиновая константа ошибки во встроенном браузере;
  Android использует один `NativeUi.BRIGHT_RED`.

Версия панелей остаётся v125. Сборка локальная, публикация не выполнялась.
