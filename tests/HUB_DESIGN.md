# Дизайн панели Hub (локально, v121)

В разделе «Эффекты → Эффекты Hub» ниже переключателей эффектов добавлен
раздел «Дизайн», одинаковый на ПК и мобильных устройствах:

- Обычный — прежнее оформление.
- Зимний — синяя палитра, ледяные панели, статичные снежные детали.
  Падающий снег включается отдельно в эффектах.
- Для слабых устройств — сплошной фон, без CSS-анимаций, переходов,
  размытия, теней и canvas-эффектов. Частицы удаляются, буфер canvas
  уменьшается до 1×1, цикл requestAnimationFrame отменяется.

Выбор хранится в localStorage этого браузера, применяется перед отрисовкой
страницы и синхронизируется между вкладками. Настройка применяется ко всем
сгенерированным страницам Hub: к главной панели, авторизации, VPS/SSH-терминалу,
логам, заметкам и очереди обновления. Ответы проксируемого LuCI намеренно
остаются без изменений.
Выбранный эффект Hub также читается на этих страницах из того же значения
`owrtRemote:seasonEffectMode`: снег, дождь, космос, угли, орбита, призма,
пульс и лучи имеют отдельную отрисовку. В lite-режиме эффекты отключены.
На страницах авторизации, терминала и очереди старые фоновые aura-анимации
отключаются, чтобы они не смешивались с выбранным эффектом Hub.
При возврате из облегчённого дизайна восстанавливается выбранный ранее эффект.

В лёгком режиме ресурсы VPS обновляются раз в 5 секунд, роутеры — раз в 10.
В остальных дизайнах сохраняются интервалы 1 и 5 секунд. Скрытые вкладки
приостанавливают эффекты и автоматические запросы статистики/роутеров.
Автоматические запросы списка роутеров не перекрываются, имеют тайм-аут 10 с.
Неизменившийся ответ в лёгком режиме не вызывает пересоздание карточек.
Уведомления, Heartbeat, Xray, WAN и настройки роутеров не менялись.

Установка на VPS из PowerShell Windows 11:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\k.zolotarev95\Documents\openwrt overlay\vps\deploy-hub-design.ps1" -Vps "root@138.124.79.58" -Action Install
```

После установки обновить страницу и открыть «Эффекты → Дизайн».
Откат — та же команда с `-Action Rollback`. Резервная копия:
`/opt/owrt-remote/owrt-remote-hub.py.bak-before-hub-design-v121`.
При сбое установки возвращается файл, который был до этой попытки.
Скрипт подтверждает SHA-256 реально запущенного Hub через health endpoint.

Проверки:

```text
python -m unittest tests.test_hub_design_deploy tests.test_vps_resources -q
python -m unittest tests.test_hub_design_global -q
node tests/test_hub_design_ui.cjs
node tests/test_hub_design_polling.cjs .test-output/hub-design/dashboard.js
node tests/test_vps_resources_ui.cjs .test-output/hub-design/dashboard.js
```

Браузерные проверки используют Playwright/Chrome и локальные ответы API.
Проверяют ПК, телефон и горизонтальный экран; сохранение после перезагрузки,
отключение эффектов/буфера в lite, восстановление эффектов, отсутствие
горизонтального переполнения. Снимки сохраняются в `.test-output/hub-design/`.
Это функциональные проверки экономии работы браузера, а не замер FPS или
потребления памяти на физическом слабом устройстве.
