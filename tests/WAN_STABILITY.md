# Исправление запуска прямого WAN в v121

На проблемном роутере обычный `wan` был поднят, имел IPv4-адрес,
маршрут и рабочий DNS. Проверка `ip -4 route show table 210` возвращала
`Dump terminated`, а `wan-preflight` — код 1. Генерация Xray-конфигурации
прерывалась, но агент всё равно запускал Xray с пустым аргументом `-config`.
В журнале появлялось `Failed to get format of`, затем procd останавливал
instance после шести падений. Из-за остановленного туннеля Hub показывал
роутер офлайн и ошибки proxy.

Теперь после такой ошибки чтения таблицы выполняется дополнительное
чтение всех таблиц. Только успешный полный вывод позволяет проверить,
пуста ли таблица 210. Учитываются её числовой ID и имена из `rt_tables`.
Чужая таблица или неудачный повторный запрос по-прежнему блокируют
подготовку WAN. Ошибка генерации, пустой путь или отсутствующий файл
конфигурации останавливают агент до запуска Xray.

Изменены только `files/usr/lib/owrt-remote/wan.sh` и
`files/usr/sbin/owrt-remote`. Версия остаётся v121. Настройки Podkop,
LAN и источники установки GitHub/GitLab не меняются. Обновление VPS
для этого исправления не требуется.

Установка из PowerShell Windows 11:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\k.zolotarev95\Documents\openwrt overlay\vps\deploy-wan-stability-fix.ps1" -Router "root@192.168.1.1" -Action Install
```

Скрипт перед заменой проверяет синтаксис и подготовку WAN новым helper,
сохраняет агент, helper, UCI и Xray-конфигурацию в
`/root/owrt-remote-backup-before-wan-stability-v121`. Сохранённая копия
не перезаписывается при повторной установке. После замены выполняются
перезапуск, проверка процесса Xray и настоящий heartbeat до Hub.
При ошибке восстанавливается состояние до текущей попытки.
Успех подтверждается `WAN_STABILITY_ROUTER_Install_OK`.

Откат из того же PowerShell:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "C:\Users\k.zolotarev95\Documents\openwrt overlay\vps\deploy-wan-stability-fix.ps1" -Router "root@192.168.1.1" -Action Rollback
```

Откат возвращает также настройки, сохранённые перед установкой. Если
в момент сохранения старый WAN-режим уже был включён и сломан, откат
вернёт и этот режим; его можно выключить в панели роутера.
Резервная копия хранится на конкретном роутере: установка на одном
IP не создаёт копию на другом. При отсутствии или неполноте копии
скрипт сообщает причину и завершает откат до остановки сервиса.

Локальные тесты с подменёнными OpenWrt UCI/ip/netifd проверяют ошибку
пустой таблицы, именованную чужую таблицу, отказ в чтении, запрет
пустой конфигурации и успешный запуск с корректной конфигурацией.
Также запускаются существующие проверки резервирования WAN, формы
выбора интерфейсов и применения Xray-команд. Все 64 проверки прошли;
PowerShell и подготовленные shell-скрипты установки/отката прошли
проверку синтаксиса, payload подготовлен в UTF-8 без BOM с LF.
Три дополнительные проверки отката подтверждают восстановление
полной копии и отсутствие изменений при отсутствующей/неполной копии.
Реальное устройство проверяет пользователь.
