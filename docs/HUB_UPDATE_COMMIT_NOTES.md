# Описание изменений при обновлении Hub

В подтверждении обновления панели VPS показываются:

- версия и контрольная сборка файла Hub;
- источник обновления GitHub;
- русское описание изменений этой сборки.

Текст хранится в самой сборке Hub в `HUB_UPDATE_NOTES` и выводится через
`textContent`. Поэтому описание относится именно к устанавливаемой сборке и
не зависит от названия Git-коммита.

При каждом изменении нужно обновлять `HUB_UPDATE_NOTES` от лица проекта:

```text
Исправили обслуживание журналов VPS.
Добавили поддержку CSQTT и проверку journald.
```

Проверка выполняется при каждом поиске новой сборки. Обычная установка уже
проверенного файла остаётся привязанной к SHA256 Hub; описание используется
только для показа пользователю.
