- На карте по умолчанию восемь роутеров; на остальных платформах семь.

  Анимация выполняется CSS, без дополнительного опроса сервера и JS-таймеров.
  Скрытая карта и фон не анимируются; reduced-motion и лёгкий дизайн соблюдаются.
- Кольцо диска и показатели расположены по центру.
- Исправлен прямой доступ к отсутствующему `Notification`: он прерывал
  инициализацию дашборда в WebKit без поддержки уведомлений.

## Certbot

`nginx_policies()` разрешает только точный существующий файл
`/etc/letsencrypt/options-ssl-nginx.conf` после `Path.resolve()`. Этот файл
не редактируется. Другие внешние конфиги, похожие имена, отсутствующий файл
и ссылка из него за пределы разрешённого пути по-прежнему отклоняются.
Права файлов логов не меняются; проверки nginx и SHA256 сохранены.

Встроенный скрипт пересобран командой `python scripts/embed-log-maintenance.py`.
SHA256: `49d0dc3b4526f4897a39096d5e1ec3de99ce2a419a99639d96f58e79ba05f5c2`.

## Установка — PowerShell Windows 11

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-ios-android-certbot-fix.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Скрипт проверяет и устанавливает Hub/мобильный API, затем отдельно устанавливает
проверенный встроенный компонент обслуживания. Бэкап Hub:
`/root/owrt-remote-backup-before-ios-android-certbot-v125`;
настройки обслуживания сохраняются в его подкаталоге `maintenance`.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Откат восстанавливает исходники и настройки обслуживания; уже удалённые по
обычным правилам ротации архивы восстановить нельзя.

Android: [CHANGES-0.3.5.md](../android/CHANGES-0.3.5.md).

- Настоящий HTML Hub в Chromium и WebKit: 320/390/430/844 px, восемь узлов,
  размеры статистики, центр диска, координаты линий, движение dashoffset,
  раскрытие всех, поворот, отсутствие переполнения и ошибок JS.
- Проверки iOS установки на экран «Домой» и восстановления сессии прошли.
- 33 теста механизма обновления Hub прошли; проверки встроенных компонентов
  подтверждают совпадение исходников и SHA256.
- Все 16 проверок обслуживания прошли в Linux без пропусков. Новый PowerShell
  установщик проверен на той же VM: установка Hub/API/компонента и откат,
  проверка ревизии, `nginx -t` и активных служб завершились успешно.
- В изолированной Ubuntu 24.04.5 VM установлены nginx 1.24 и Certbot 2.9 из
  репозитория Ubuntu. Подключён штатный SSL-файл пакета Certbot, создан локальный
  тестовый сертификат. Ошибка опубликованной v124 воспроизведена. Новая установка
  обслуживания, запуск и откат прошли. Настоящий worker опубликованного тега
  v124 успешно установил локальную v125, подтвердил ревизию и receipt SHA256.
  SSL-файл, права nginx/error.log и целостность SQLite проверены после обновления.
- Ubuntu 26.04 отдельно не запускалась: точный отказ из сообщения покрыт
  проверкой путей и воспроизведён со штатным Certbot на Ubuntu 24.04.

Работа локальная. На VPS пользователя не устанавливалось, push/тег/релиз не выполнялись.
