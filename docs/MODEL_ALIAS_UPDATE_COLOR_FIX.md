# Netcore N60 Pro, версии Routerich AX3000 и цвет обновления

Исправление v125, ревизия 4, для обновления из `main`.
Выпуск тега и релизных пакетов выполняется отдельно; опубликованная r3
сохраняется. Ревизия защищает эти файлы от замены более ранней сборкой.

## Модели

- `Netcore N60 Pro` и board ID `netcore,n60-pro` используют существующую
  фотографию Netis NX62. Поле «Модель» и подпись изображения показывают
  `Netcore N60 Pro (Netis NX62)`. Пользовательское имя карточки и исходное
  значение Heartbeat не переписываются. Для `Netis NX62` подпись сохраняется.
- Только для семейства Routerich AX3000 разрешено общее изображение с числовой
  версией: `v1`, `v1.0`, `v2`, `v3`, `v12.3` и т. п. Показанное название
  сохраняет фактическую ревизию устройства. Варианты Pro/Plus, AX30000 и
  неизвестные ревизии других моделей не подставляют эту фотографию.
- Правила находятся в общем каталоге (`display_aliases`, `revision_aliases`)
  и входят в автономный bundle Hub. Источники и SHA256 фотографий не изменены.
  Метаданные и обработка синхронизированы в Android; опубликованная APK
  пока остаётся прежней. Проверка Android выполняется отдельной локальной сборкой.

## Обновление панели роутера

Раньше у состояния `available` не было своего цвета. Добавлен `--amber`
из общей палитры VPS: жёлтый текст верхней кнопки и сообщения диалога,
мягкий фон и рамка кнопки. Зелёные состояния `current`/`local_newer` сохранены.
Проверены обычный, зимний и облегчённый дизайны.

## Установка — PowerShell Windows 11

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-model-alias-update-color.ps1'
# Изображения и названия в панели VPS:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
# Цвет обновления в панели роутера:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Install
```

После установки обновите страницы через Ctrl+F5. Установщик VPS подтверждает
запущенный SHA256 и мобильный API; установщик роутера проверяет семь файлов
панели/обновления. Конфигурация UCI и рабочий Xray не заменяются.

Откат к отдельным резервным копиям:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Rollback
```

VPS: `/root/owrt-remote-backup-before-model-alias-v125`.
Роутер: `/root/owrt-remote-backup-before-update-amber-v125`.
