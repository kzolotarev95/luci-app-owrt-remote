# Раскрытие данных карточек роутеров

На ПК и телефоне карточки открываются кнопками «Открыть данные» и «Скрыть данные».
На ПК подробности раскрываются поверх сетки. Место компактной карточки сохраняется,
поэтому соседние карточки, следующие ряды и высота страницы не меняются.
Одновременно открыта одна карточка. Закрыть её можно кнопкой, Escape или нажатием
снаружи. Длинное содержимое прокручивается внутри раскрытой карточки.

Раскрытие занимает 230 мс. В облегчённом дизайне и при системной настройке уменьшения
анимации переход выполняется сразу. На мобильном сохраняется раскрытие внутри
страницы. Обновление статусов сохраняет открытые данные и их прокрутку.

## Локальная установка на VPS

Из PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-router-card-details.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@YOUR_VPS_IP -Action Install
```

Скрипт проверяет Python, сохраняет исходный Hub в
`/root/owrt-remote-backup-before-router-card-details-v122/hub.py`, атомарно заменяет
файл, перезапускает Hub и проверяет SHA256 работающего процесса через `/health`.
При ошибке восстанавливает файл, который был установлен до текущей попытки.
После установки обновите страницу панели через Ctrl+F5.

Откат к сохранённой копии:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@YOUR_VPS_IP -Action Rollback
```

## Проверка интерфейса

`tests/test_router_card_details.cjs` использует настоящий HTML/JS панели и
Playwright с установленным Chrome. Проверяет координаты сетки во время анимации,
раскрытие/закрытие, границы экрана, быстрые повторные клики, обновление статусов,
прокрутку, фокус клавиатуры и переход с ПК на мобильный размер. Сценарии включают
три дизайна, уменьшенную анимацию, две колонки и обе ориентации телефона.
