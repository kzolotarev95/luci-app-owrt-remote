# Баннер диска и поведение дашборда — локальная v125

Вместо блока «Ресурсы VPS» показан баннер «Диск VPS»: круг заполнения,
процент занятого места, свободный/занятый/общий объём и раздел `/`.
При заполнении от 90% индикатор красный. Недоступные измерения показываются
как «—». Данные поступают через существующий опрос `/api/vps/resources`;
дополнительный запрос или таймер не добавлен. ЦП и ОЗУ остались в верхних KPI.

«Скрыть статистику / Открыть статистику» сохраняет выбор в localStorage
текущего браузера (`owrtRemote:routerStatsVisible`). Он применяется до первого
отображения верхних KPI и сохраняется при перезагрузке, возврате на страницу
и изменении размера окна. Прежняя мобильная функция больше не принуждает
статистику открываться на ПК. Вкладки одного Hub получают изменение через
событие `storage`. При запрете хранилища переключатель работает в текущей вкладке.

После успешного POST создания роутера страница перезагружается сразу.
Повторная отправка блокируется на время запроса. При ошибке сервера или сети
страница остаётся открытой, введённые значения сохраняются, показана ошибка.

У подставок фотографий используется золотистый `--amber` ссылки поддержки
вместо зелёного `--cyan`. Сами фотографии устройств не перекрашиваются.

## Проверки

- `python -m unittest tests.test_vps_resources` — измерения, SSR, отсутствие данных.
- `node tests/test_vantage_dashboard.cjs` — 24 сочетания экранов и количества роутеров,
  обновление диска, сохранение статистики, успех и ошибки создания.
- `node tests/test_router_model_photos.cjs` — реальные фото на 320–2560 px.
- `node tests/test_vps_resources_ui.cjs .test-output/disk-banner/dashboard.js` — один
  запрос за раз, тайм-ауты, потеря сети, остановка опроса скрытой вкладки.
- Проверки актуальности обоих встроенных наборов ресурсов и подготовка установщика.

Для VM-теста предварительно выполнить
`python tests/test_vps_resources.py --export-preview .test-output/disk-banner`.
Браузерным тестам нужен Playwright в локальном `NODE_PATH`.

## Установка и откат

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-dashboard-disk-fix.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Откат:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-dashboard-disk-v125`.
Устанавливается текущая локальная сборка Hub. После установки обновите панель
через Ctrl+F5. Обновление роутерного агента для этих изменений не требуется.
