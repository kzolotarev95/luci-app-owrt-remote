# OWRT Hub v125-r2

Исправления обновления VPS и панели роутера. Версия в интерфейсе остаётся
v125, пакетная ревизия — 125-r2. Старый выпуск v125 и его пакеты сохранены.

## Панель роутера

- Исправлена ошибка «Обновление требует подтверждённого POST-запроса панели».
  OpenWrt uhttpd не передаёт произвольный заголовок в CGI. Теперь подтверждение
  из авторизованной страницы передаётся в теле POST; авторизация и запрет
  неподтверждённых запросов сохранены.
- Обновлён ключ кэша JavaScript и пересчитан манифест SHA256.
- «Установлена последняя версия» и «Установлена локальная версия» отображаются
  зелёным, включая зимний и облегчённый дизайн. Более старая ревизия
  не устанавливается поверх новой.

## VPS

- Устранён отказ `Custom /etc/logrotate.d/owrt-remote found; manual review required`
  для корректного пользовательского правила. Файл сохраняется и проверяется
  в общем дереве logrotate. Проверки владельца, прав, ссылок, допустимых путей,
  nginx/Certbot и SHA256 продолжают действовать.
- Ошибка установки больше не сопровождается зелёным статусом «последняя версия».
  Панель показывает причину и предлагает повторную проверку или обновление.
  Повтор той же сборки после неудачи разрешён; параллельные установки блокируются.
- Добавлено сравнение версии вместе с ревизией. Старая v125-r1 не предлагается
  как обновление локальной v125-r2. Проверка выполняется в API и установщике;
  новые сборки той же ревизии и следующие версии доступны для обновления.
- Локальный скрипт восстановления сохраняет пользовательский конфиг и архивирует
  прежнюю ошибку только после проверки обслуживания, таймера и запущенной сборки.

## Как обновиться

На VPS используйте «Обновление панели» / «Повторить обновление».

Если на роутере v125-r1 уже не может проверить обновление из-за POST-ошибки,
один раз установите пакет 125-r2 через LuCI/SSH либо обновите его установщиком
проекта или через раздел Hub «Обновить роутеры». После этого кнопка обновления
на роутере работает через штатный uhttpd. Настройки UCI, ключи и рабочий Xray
сохраняются.

В Assets этого выпуска находятся IPK для OpenWrt 23.05/24.10, APK для OpenWrt
25.12 и SHA256SUMS. Это универсальные пакеты `all`/`noarch`, без встроенного
бинарника Xray. APK OpenWrt предназначен для роутера.

Android-приложение в r2 не изменялось: актуальна
[APK Android 0.3.12-v125 из выпуска v125](https://github.com/kzolotarev95/luci-app-owrt-remote/releases/tag/v125).

## Проверка

- 32 теста обновления VPS: версии/ревизии, повтор после ошибки, независимый
  worker, проверка результата, восстановление и защита API.
- Проверки интерфейса обновления на ПК и мобильной ширине 390 px.
- Реальная OpenWrt VM с uhttpd: POST без нестандартного CGI-заголовка,
  проверка/установка, отказ неверным запросам, откат и восстановление транзакции.
- Ubuntu 24.04 с nginx, Certbot, systemd и logrotate: исходная ошибка,
  установка/очистка/откат с сохранением пользовательского правила,
  базы Hub, ключей и прав на логи.
- Автоматический выпуск проверяет сборку в 30 официальных SDK и установку,
  обновление с предыдущего опубликованного пакета и удаление в OpenWrt VM
  для трёх поддерживаемых веток. Пакеты публикуются после успешных проверок.
