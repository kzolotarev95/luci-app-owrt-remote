# Обновление панели роутера через кнопку

Верхняя кнопка и пункт «Настройки → Обновление панели» открывают одно окно.
Панель автоматически проверяет источник при первом открытии и повторяет
проверку устаревшего результата при следующем входе. Проверку можно запустить
вручную. Только совпадение всех SHA256 означает «Установлена последняя версия».
Исправления внутри одной версии тоже обнаруживаются. Более старая версия
GitHub не заменяет более новую локальную сборку.

После проверки доступна кнопка «Обновить панель». Подтверждается конкретная
ревизия GitHub; если main изменился, необходимо повторить проверку. Новый
номер интерфейса для этого исправления не вводится: текущая локальная v125.

## Как устроено обновление

- Источник: только `kzolotarev95/luci-app-owrt-remote` на GitHub.
- Commit `main` разрешается через GitHub API. Манифест и все файлы загружаются
  из этого неизменяемого commit, с обычной проверкой HTTPS-сертификатов.
- `router-update.manifest` содержит версию, ревизию и SHA256 фиксированного
  списка файлов агента, CGI, LuCI и вспомогательных скриптов. Произвольные пути,
  дубликаты, неподходящий формат и режимы файлов отвергаются.
- После загрузки проверяются SHA256, shell-синтаксис, JSON и версия.
  Файлы скачиваются до начала замены; выполняются атомарные переименования.
- Сохраняется последняя предыдущая сборка в
  `/etc/owrt-remote/panel-update-backup`. Ошибка замены или перезапуска службы
  запускает восстановление. Незавершённая транзакция распознаётся при
  следующей задаче и сначала восстанавливается.
- UCI-конфигурация, ключ панели, Xray JSON, бинарник Xray, постоянный Xray-кэш
  и маркер удалённой остановки Xray не входят в обновляемый список.
  Xray заново не скачивается. Выключенная служба не включается.
- Активная служба перезапускается и проверяется; при ранее работающем Xray
  проверяется и его процесс. Remote-остановка Xray сохраняется.
- Это обновление установленных runtime-файлов, как при установке через
  `install.sh`; opkg/apk и их база установленных пакетов не изменяются.
  Обновление системных зависимостей и прошивки в эту кнопку не входит.
- Задача выполняется независимо от HTTP-запроса. Перезапуск Xray может
  ненадолго оборвать удалённый доступ; страница повторяет запрос статуса.
  Повторное открытие страницы не создаёт ещё одну установку.
- Старт требует ключ панели, POST и специальный заголовок. GET только
  читает статус. Используется один процесс обновления и один запрос
  браузера за раз. Временный статус в `/tmp` не является журналом событий.
  Удалённая ранее функция «Глобальные логи» не возвращается.

## Локальная установка и откат (Windows PowerShell)

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-router-panel-update.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Install
```

Обновить страницу с очисткой браузерного кэша. Первая установка модуля через
PowerShell обновляет только файлы интерфейса и обновляющего модуля, без
перезапуска uhttpd, Xray или службы Remote. Резервная копия:
`/root/owrt-remote-backup-before-router-panel-update-v125`.

Откат первой установки модуля:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Rollback
```

Отдельно: откат обновления, уже установленного кнопкой:

```powershell
ssh root@192.168.2.1 'sh /usr/lib/owrt-remote/panel-update.sh rollback'
ssh root@192.168.2.1 'sh /usr/lib/owrt-remote/panel-update.sh status'
```

До публикации этих файлов GitHub ещё не содержит нового манифеста. Это
отображается как ошибка проверки источника; сообщение «последняя версия»
не подставляется. Локальное тестирование использует отдельный источник-
фикстуру, без изменения настоящих ссылок установки.

## Обслуживание исходников и проверка

После изменения runtime-файлов перед публикацией:

```powershell
python scripts/embed-dashboard-design.py
python scripts/router-update-manifest.py
python scripts/router-update-manifest.py --check
python -m unittest discover -s tests -p 'test_router_panel_update*.py' -v
node tests/test_router_panel_update.cjs
```

Релизная GitHub Actions проверяет актуальность манифеста до сборки IPK/APK.
Новые файлы входят и в обычный `install.sh`, и в пакетный payload для всех
архитектур (shell/JS, без нативного кода).

`scripts/test-router-panel-update-vm.py` проверяет настоящий BusyBox ash,
jsonfilter, TLS-загрузку через отдельный тестовый CA, фоновый процесс,
блокировку параллельных задач, установку, HTTP-ошибки, SHA256, перезапуск,
откат, сохранность конфигурации и авторизованный CGI в одноразовой OpenWrt VM.
Сертификат, подмена транспортного адреса и фикстуры используются только
в тестовой VM. На роутер пользователя они не устанавливаются.

Локальная проверка 27.11.2026: 17 тестов транзакции/CGI/первой установки и
отката, 3 браузерных сценария обновления (1920/390/320), 7 сценариев обычной
панели, 24 проверки пакетного инструментария. В OpenWrt 25.12.6 VM проверены
настоящие ash/jsonfilter/TLS и фоновая установка, включая прерывание транзакции,
защиту повреждённой резервной копии и откат. Проверка на физическом роутере
пользователя остаётся следующим шагом после локальной установки модуля.
