# Выборочное обновление роутеров

«Управление → Обновить роутеры» открывает общий список всех роутеров Hub.
При первом открытии отмечены все устройства. Можно снять отдельные галочки,
выбрать все устройства, только находящиеся в сети или снять весь выбор.
В очереди используются только отмеченные устройства, в порядке списка.
Новые роутеры, появившиеся после загрузки списка, не выбираются автоматически.
Офлайн-роутер разрешено выбрать: связь Heartbeat и доступность SSH различаются.

Для каждого роутера доступен способ входа root:

- «Общий пароль» — пароль из общего поля; если оно пустое, используется SSH-ключ VPS.
- «Свой пароль» — отдельный непустой пароль этого роутера.
- «SSH-ключ» — ключ VPS, даже если общий пароль заполнен.

«Обновить выбранные» запускает указанную команду обновления по очереди.
«Перезапустить выбранные» использует тот же выбор устройств и способы входа.
Ошибка авторизации одного устройства не мешает обработать следующие устройства.
Обновлённый агент на роутере для выбора устройств не требуется: команды по-прежнему
выполняются через SSH-туннель. Эта функция не работает через один только Heartbeat.

Пароли не записываются в базу, файлы, localStorage или sessionStorage.
В браузере они хранятся только в текущей открытой странице, а на VPS — в памяти
обработчика запроса и текущей очереди. Поля очищаются после попытки запуска
и при уходе со страницы; рабочий поток освобождает свои данные при завершении.
Опрос статусов сохраняет выбор, фокус и введённые значения без пересоздания полей.

Сервер проверяет идентификаторы и не подменяет пустой или ошибочный выбор полным
списком. Отдельные пароли принимаются только для выбранных устройств и не
возвращаются в ответах API. Права владельца, CSRF и проверка Origin сохранены.
Старые клиенты без поля `router_ids` сохраняют прежний запуск на всех устройствах.

## Локальная установка и откат

В PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-router-update-selection.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Установщик сохраняет исходник Hub и модуль мобильного API в
`/root/owrt-remote-backup-before-router-update-selection-v124`, проверяет кандидата,
перезапускает Hub и проверяет фактически запущенную ревизию. Роутеры не изменяются.
Не выполняйте установку во время активной очереди: перезапуск Hub прервёт наблюдение
за ней, а уже запущенная на роутере установка продолжится.

Откат файлов из этой резервной копии:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Проверки: `tests/test_router_updates.py` (выбор, индивидуальные пароли, ключи,
ошибки, права/API) и `tests/test_router_updates_ui.cjs` (ПК/телефон, сохранение
полей при опросе, отсутствие паролей в хранилищах, управление очередью).
