# VPS host через Heartbeat

Владелец Hub открывает карточку → «Открыть данные» → «Настроить VPS host».
Вводит IP/домен без URL и порта, выбирает ручной/автоматический режим и нажимает
«Сохранить и перезапустить Xray». Пароль SSH не нужен. Требуются обновлённый Hub
и агент с возможностью `vps_host_control=1` на выбранном роутере.

Hub сохраняет типизированную команду с ID в общей очереди управления Xray.
Команда доставляется только в ответе на аутентифицированный Heartbeat этого
роутера. Остановка Xray не выключает Heartbeat. Команды Xray и смена адреса
выполняются последовательно; повторная доставка ID не повторяет перезапуск.
Старая версия агента получает понятное требование обновления, без попыток SSH.

Агент сохраняет предыдущие адрес, режим и JSON в закрытом каталоге
`/etc/owrt-remote/control/host-backup-<id>` на постоянном разделе. Сохраняется
одна предыдущая копия. Новый JSON проходит штатную проверку Xray до замены.
Меняются только VPS host и его режим, Hub URL и остальные параметры сохраняются.
Перезапускается instance Xray; heartbeat и обработчик команды не останавливаются.
При ошибке применения обработчик восстанавливает прежние параметры и JSON,
пытается вернуть прежнее состояние Xray и сообщает результат восстановления.

Hub подтверждает успех только после ответа агента с совпадающими ID, адресом,
режимом, `rc=0` и работающим Xray. До подтверждения основной адрес в базе не
заменяется. Пока команда выполняется, автоматическое обновление адреса через
heartbeat не возвращает старое значение. Этапы и итог видны в форме VPS host
и истории «Настройки Xray». Они сохраняются после обновления страницы/Hub.
Форма использует существующее обновление карточек, без нового цикла опроса.

Агент помечает каждый снимок ID загрузки ядра и монотонным временем его
подготовки. Hub последовательно принимает только свежие снимки этой загрузки;
повторные, запоздавшие и пакеты предыдущей загрузки не меняют статус, не получают
команды и настройки Hub. После обновления агента старый процесс без этих полей
не подменяет свежий статус в пределах интервала доступности. После прекращения
новых отчётов предусмотрен переход к старому агенту для намеренного отката.
Недавний подтверждённый результат также защищён от пакета старого процесса
во время перехода на этот протокол. В браузере поздний ответ GET не заменяет
более новый список или подтверждённый ответ сохранения.

Надпись об успешной смене адреса отделена от актуального состояния: при другом
адресе/режиме показывается расхождение, при остановленном Xray — его остановка.
Предложение обновить неподдерживаемый агент не сопровождается утверждением
о текущем успешном запуске. Если после установки обеих частей всё ещё чередуются
разные устройства, нужно проверить уникальность Router ID и запущенные агенты.

Если за 3 минуты агент не получил команду, она отменяется. Если доставка была,
но итог потерян, показывается «Результат не подтверждён»; поздний подтверждённый
ответ может завершить команду. Успех запуска подтверждает процесс и настройки,
а не доступность произвольного введённого VPS: адрес, порт, сервер Xray и ключи
должны соответствовать друг другу. Без интернета/heartbeat команды не доставить.

Первое обновление старого агента требует действующего доступа к роутеру
(например, по LAN). Новую функцию нельзя добавить старому агенту одной сменой
кода VPS.

## Локальная установка и откат (Windows PowerShell)

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-vps-host-heartbeat.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Install
```

Снимки файлов — `/root/owrt-remote-backup-before-vps-host-heartbeat-v124` отдельно
на VPS и роутере. Откат файлов (база Hub и параметры UCI не откатываются):

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Rollback
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```
