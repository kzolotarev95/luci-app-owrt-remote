# Фотографии моделей роутеров — локальная v125

В карте подключений и карточках VPS-панели отображается фотография модели,
которую сообщил агент. Пользовательское имя («Основа», «Советская 30») и ID
не используются для выбора изображения и не меняются.

Фотографии сохраняются для офлайн-роутеров с известной моделью. Если роутер
ещё не присылал модель, модель не распознана либо изображение не загрузилось,
показывается нейтральная иконка. Похожая модель другого производителя или
неизвестная ревизия автоматически не подставляется.

## Каталог и источники

Основа списка: [OpenWrt Router Compare](https://hattabbi4.github.io/openwrt-router-compare/),
92 позиции на 26 ноября 2026 года. Подобраны фотографии для 80 позиций и
восьми дополнительных моделей: netis N6, Xiaomi Mi Router 4A Gigabit Edition,
Xiaomi Mi Router 3G, Cudy WR3000, GL.iNet GL-MT1300, TP-Link Archer C6 v3,
ASUS RT-AX53U, Xiaomi Redmi Router AX6S. Дополнительно включены фото
Friendly NanoPi R3S и отдельная иллюстрация QEMU Standard PC: всего 90 изображений.

Источники, оригинальные URL и SHA256 сохранены для каждого изображения в
[catalog.json](../vps/router-model-photos/catalog.json). Использованы
фотографии производителей, аппаратной базы TechInfoDepot, владельцев устройств
и страниц конкретных моделей. Фотографии подготовлены как прозрачные WebP
320×240 с сохранением пропорций и полями для антенн. Для Cudy WBR3000UAX
использован предоставленный пользователем оригинал; это отмечено в каталоге.
Названия и источники не генерируются во время работы панели.

## Карточки устройств

Все изображения оформлены одинаково: тёмная подставка с мягкой подсветкой,
скошенной кромкой и тенью под устройством. Объём создаётся CSS; фотография
конкретной модели сохраняется. Из рекламных исходников убраны надписи,
соседние устройства и фон. На карте и в карточках используется один файл.

В карточке фотография крупнее, на карте — компактнее; размеры адаптированы
для телефона. Наведение слегка приподнимает мини-карточку на ПК. В режиме
для слабых устройств отключены тени и анимация; системная настройка уменьшения
движения также учитывается. При обновлении статусов изображения не мигают.

Подготовка изображений выполняется при разработке. На VPS не загружаются
модели обработки изображений, не выполняется вырезание фона и не добавляются
зависимости Python. Нейтральная иконка неизвестной модели имеет ту же подставку.

При повторной проверке исправлено удаление светлых антенн маской фона.
Для AX3000T выбран полный ракурс с четырьмя поднятыми антеннами; контрольные
участки корпуса и антенн проверяются по пикселям готового WebP. Подробности
и объединённый установщик: [общая палитра и проверка фото](SHARED_PALETTE_PHOTO_FIX.md).

Подтверждённой подходящей фотографии пока нет для:

- CMCC A10;
- Gemtek XR1710G;
- JDCloud RE-CP-03;
- Konka KOMI A31;
- Netcore N60;
- Nokia EA0326GMP;
- Qihoo 360T7;
- Routerich BE7200;
- TP-Link TL-7DR7250 v1;
- TP-Link TL-XDR6086;
- Zbtlink ZBT-Z8114AX-DS;
- Zbtlink ZBT-Z8803BE.

Эти позиции перечислены в каталоге с `file: null` и используют нейтральную
иконку. Поисковые результаты с другими устройствами, изображениями коробки,
характеристиками вместо устройства либо неподтверждённым соответствием
не выдаются за фотографию нужного роутера.

После ошибки загрузки повторная попытка выполняется при обновлении страницы;
обычный опрос статусов не создаёт бесконечных повторных запросов изображения.

### Cudy TR3000: названия одной модели

`Cudy TR3000 v1` и `Cudy TR3000 256MB v1` используют одну существующую фотографию
`cudy-tr3000.webp`. Добавлено точное соответствие для строки с `256MB`, которую
может передавать агент OpenWrt. Произвольные другие ревизии не подставляются.
Сопоставление работает одинаково в карточках и карте подключений.

Локальная установка исправления с отдельной резервной копией, PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-cudy-tr3000-photo-fix.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
# Откат:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-cudy-tr3000-photo-v125`.
Как и остальные локальные установщики интерфейса, скрипт доставляет текущий Hub
с накопленными локальными изменениями v125. Роутер обновлять для фотографии не нужно.
Проверены оба названия, совпадение URL фотографии, HTTP-кэш и браузерные размеры
320, 390, 1366 и 2560 px. Установка на реальный VPS выполняется пользователем отдельно.

### Xiaomi Redmi Router AX6S

Модель отсутствовала в каталоге, поэтому использовалась нейтральная иконка.
Добавлена фотография именно AX6S, прозрачный WebP 320×240 с полями вокруг
всех шести антенн. Источник: [карточка AX6S (DVB4326CN)](https://catalog.onliner.by/wrouter/xiaomi/dvb4326cn).
URL оригинала и его SHA256 сохранены в каталоге; контрольные точки всех
шести антенн и корпуса проверяются существующим браузерным тестом.

Поддержаны названия Xiaomi Redmi Router AX6S, Xiaomi Redmi AX6S,
Redmi Router AX6S, Redmi AX6S и Xiaomi Redmi Aiot AX6S. Модели AX6, AX6000
и неизвестные ревизии не подменяются изображением AX6S. Один файл используется
в карточках и карте подключений VPS/ПК/iOS, копия синхронизирована в Android.

### Friendly NanoPi R3S и QEMU Standard PC

Добавлены изображение R3S и карточка виртуальной машины QEMU. Тип изображения,
источник и SHA256 указаны в каталоге; поддержаны точные строки моделей и aliases.
Netis NX62 в этом исправлении не менялся и отложен для отдельной проверки.
Подробнее: [изображения и проверка nginx-модулей](MODELS_NGINX_MODULE_FIX.md).
Роутерный агент обновлять для этого исправления не требуется.

Установка локального исправления и откат, PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-ax6s-photo-fix.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
# Откат:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-ax6s-photo-v125`.
Скрипт доставляет текущий Hub с накопленными локальными изменениями.
Новая локальная Android APK: `artifacts/android/OWRT-Hub-Android-0.3.12-v125.apk`.
Проверены карточки, карта и совпадение названий в Chromium 320/390/1366/2560 px
и WebKit с iOS-профилем 390 px; все шесть антенн проходят проверку альфы.
Три серверных теста каталога/HTTP-кэша прошли. Android assembleDebug/lintDebug
успешны; фото и каталог внутри APK побайтно сверены с источником, подпись
совпадает с предыдущими локальными сборками.

## Доставка и кэш

Фото встроены в Hub вместе с каталогом. Начальная установка и обновление
одного `owrt-remote-hub.py` доставляют полный набор; копирование отдельного
каталога изображений на VPS не требуется. Браузер загружает только используемые
фотографии с `/router-model-photos/` своего VPS, без внешних сайтов.

Имя файла содержит SHA256. Изображения кэшируются браузером, поддерживают
ETag/304, а изменение фотографии меняет её URL. Отдельного цикла опроса нет.
Данные устройства и права доступа к роутерам сохраняют существующую логику.

## Установка и откат

В PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-router-product-cards.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Откат:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-router-product-cards-v125`.
Она отдельная от предыдущего исправления фотографий и сохраняет состояние
перед установкой нового оформления.
Устанавливается локальный Hub с накопленными изменениями v125. На роутер
для этого оформления ничего дополнительно загружать не нужно.

## Проверки для разработки

```powershell
python scripts/embed-router-model-photos.py --check
python scripts/embed-dashboard-design.py --check
python -m unittest tests.test_router_model_photos
$env:NODE_PATH = Join-Path (Get-Location) '.test-output\tachyon-browser\node_modules'
node tests/test_router_model_photos.cjs
```

После изменения каталога или фото выполните `embed-router-model-photos.py`
без `--check`. После изменения JS/CSS — `embed-dashboard-design.py`.
Локальные тесты проверяют сопоставление моделей, ошибки загрузки, HTTP-кэш,
изменение модели в Heartbeat и размеры 320–2560 px на изолированных данных.
