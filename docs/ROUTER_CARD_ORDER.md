# Перестановка карточек роутеров — локальная v125

В карточках на ПК, iOS и Android есть две стрелки и отдельный значок
перемещения. Стрелки меняют место на одну позицию среди показанных карточек.
На ПК и iOS значок можно потянуть сразу; в Android нужно удержать его,
затем перенести карточку. При перетаскивании к краю списка работает
автопрокрутка. На веб-панели Escape отменяет незавершённый жест.

В общем списке карточки переставляются внутри своей группы. В режиме
«Онлайн/Офлайн» список плоский и можно переставлять все показанные карточки.
Перестановка не назначает новую группу и не меняет настройки роутера.
Поиск и фильтры не удаляют позиции скрытых ими устройств.

Порядок хранится в SQLite Hub, отдельно для каждого пользователя. Под одним
логином на том же Hub он восстанавливается на ПК, iPhone и Android.
В другой открытой вкладке или приложении изменение появится при следующем
обычном обновлении списка. Новые устройства добавляются после упорядоченных
карточек; переименование и Heartbeat не сбрасывают порядок. Удаление роутера
удаляет его позицию, чтобы новая нода с тем же ID не наследовала её.

Если сохранить изменение не удалось, веб-панель и приложение показывают
ошибку и сохраняют прежний подтверждённый порядок. После сетевого тайм-аута
итог сверяется обычным опросом Hub: сервер мог успеть принять запрос.
На старом Hub Android показывает подсказку об обновлении и отключает стрелки.

## Установка на VPS

PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-router-card-order.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Сохраняется резервная копия Hub и мобильного API:
`/root/owrt-remote-backup-before-router-card-order-v125`.
Установщик проверяет Python, запущенную ревизию Hub и мобильный API.
Таблица `router_display_order` создаётся автоматически, остальные таблицы
и параметры подключения роутеров не заменяются.

Откат файлов из этой резервной копии:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Сохранённые позиции остаются в отдельной таблице: старый Hub её игнорирует.
Восстановление базы для отката интерфейса не требуется.

## Реализация

- `vps/router-order.js`: стрелки, Pointer Events для мыши/касания,
  автопрокрутка, отмена, подтверждение сохранения, доступные названия.
- `vps/dashboard-vantage.js` и `.css`: сортировка по сохранённым позициям,
  оформление кнопок и места вставки. Код встроен через
  `scripts/embed-dashboard-design.py`.
- `vps/owrt-remote-hub.py`: таблица позиций, API `POST /api/routers/order`,
  поле `display_order` в списке. Проверяются вход, видимость обоих роутеров,
  JSON и специальный заголовок запроса, Origin браузера. Чтение и запись
  позиции происходят в одной транзакции SQLite, чтобы параллельные изменения
  не теряли карточки. Пароли, агент и SSH для перестановки не нужны.
- Android `MainActivity.java`, `HubApiClient.java`, `ViewUpdates.java`:
  нативные стрелки и Drag and Drop, общий API, сортировка, сохранение экрана
  при фоновых обновлениях. Во время жеста опрос откладывается.

Работа подготовлена локально; публикация, пакеты и установка на VPS выполняются
отдельно по команде пользователя.

## Проверки

- `tests/test_router_order.py`: 7 проверок реального HTTP API и SQLite —
  сохранение после Heartbeat/переименования, отдельные аккаунты, ограничения
  видимости, авторизация и Origin, некорректные команды, одновременные запросы,
  удаление и повторное создание ноды.
- `tests/test_router_order.cjs`: ПК Chrome 1280 px, iOS-профиль Chrome и WebKit
  390 px — стрелки, перезагрузка, перенос с автопрокруткой, опрос во время жеста,
  Escape, ошибка сохранения, онлайн-фильтр, поиск и отдельные группы.
- `NativeRedesignInstrumentation`: 25 сценариев Android 15; дополнительно
  целевой прогон `-e routerOrderOnly true` на обычном и узком экранах 320 dp
  со шрифтом 130%. Выполняется настоящий жест касания с удержанием и переносом,
  результат проверяется по сохранённому порядку после запроса к тестовому Hub.
- Регрессии: 11 тестов удаления роутеров, 40 мобильного API, 8 сценариев
  раскрытия карточек, 8 прогонов iOS-дашборда в Chrome/WebKit — успешно.
- Сборка `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug`, проверки
  встроенных ресурсов, контрольной суммы и подписи APK, подготовка установщика
  без обращения к VPS (`-PrepareOnly`) — успешно.
