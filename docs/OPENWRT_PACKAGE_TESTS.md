# Проверка пакетной установки v121

Дата: 07.11.2026. Версия приложения: v121, ревизия пакета: 1.
Пакеты проверены локально в изолированных OpenWrt VM и успешно прошли
[GitHub Actions](https://github.com/kzolotarev95/luci-app-owrt-remote/actions/runs/42372264122).
Готовые файлы опубликованы в [Releases v121](https://github.com/kzolotarev95/luci-app-owrt-remote/releases/tag/v121).
Реальные роутеры и VPS в этих тестах не используются.

| Среда | Менеджер | Результат |
| --- | --- | --- |
| OpenWrt 23.05.6 x86_64, QEMU TCG | opkg, IPK `all` | Успешно |
| OpenWrt 24.10.8 x86_64, QEMU TCG | opkg, IPK `all` | Успешно |
| OpenWrt 25.12.6 x86_64, QEMU TCG | apk, APK v3 `noarch` | Успешно |

В каждой VM проверены:

- Чистая установка и загрузка зависимостей из репозиториев соответствующей прошивки.
- Создание приватного ключа панели, доступность CGI и пунктов LuCI.
- Синтаксис всех shell-файлов пакета штатным BusyBox ash.
- Работа службы журналов и сохранение выключенного по умолчанию Remote.
- Обновление с ревизии 1 на отдельный пакет ревизии 2.
- Побайтовое сохранение изменённого UCI, ключа панели, Xray JSON и бинарника-заглушки.
- Удаление файлов пакета и сохранение изменённой конфигурации/сгенерированных данных.
- Повторная установка с конфигурацией, не принадлежащей менеджеру пакетов.

Дополнительно:

- 22 локальных автоматических теста сборочного инструмента прошли, включая
  проверенный кэш SDK, восстановление загрузки после тайм-аута, отказ от
  неправильного HTTP Range и повреждённого архива. Дозагрузка после реального
  обрыва HTTP-ответа проверена через локальный HTTP-сервер.
- `actionlint v1.7.12` не обнаружил ошибок workflow.
- Проверены все 30 URL SDK и их записи SHA256 в официальных индексах:
  10 целевых архитектур для каждой из трёх веток.
- Подтверждён отказ штатного apk от неподписанного APK без `--allow-untrusted`.
- APK подписан отдельным тестовым RSA-ключом; после добавления публичного
  ключа штатный apk принял его без `--allow-untrusted` в проверке `--simulate`.
  Тестовый приватный ключ не входит в исходники или установочные артефакты.
- Установка не вызывала скачивание/замену рабочего Xray внутри пакетной транзакции.

Сначала проверены локальные IPK переносимого сборщика и APK настоящего
`apk-tools 3.0.9 mkpkg`. Затем из GitHub Actions скачаны пакеты и тестовые
ревизии, собранные официальными SDK. Все три SDK-пакета повторно прошли
установку, обновление и удаление в указанных VM. В SDK-отчётах записан
исходный commit `5630b64d8166a7c58506c7d479bad37589983b3f`; файлы клиента
и установочного помощника совпадают с тегом `v121`.

В CI успешно завершены 30 SDK-сборок: 10 архитектур для каждой из трёх веток,
а затем три нативные проверки установки, обновления и удаления. Публикация
выполнена только после успешного завершения обоих этапов. Все три пакета
повторно скачаны из публичного Release; их SHA256 совпали с `SHA256SUMS`
и отчётами SDK. Тестовые пакеты ревизии 2 в Release не опубликованы.

Физические ARM/MIPS-устройства, действующий Heartbeat, WAN direct и туннель
Xray с реальным Hub в этой проверке не тестировались. Код этих механизмов
не изменён пакетной доработкой.

Локальные протоколы первых проверок находятся в `.test-output/vm-23.05/`,
`.test-output/vm-24.10/`, `.test-output/vm-25.12/`. Проверки SDK-пакетов —
в `.test-output/ci-v121/sdk-vm-23.05/`, `sdk-vm-24.10/`, `sdk-vm-25.12/`.
Все тестовые VM после проверки остановлены. Пакеты и протоколы исключены из Git.
