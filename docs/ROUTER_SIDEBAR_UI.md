# Панель роутера в стиле VPS Hub

Локальная панель OpenWrt использует оформление OWRT Hub v125: графитовую
палитру, тонкие рамки, синие акценты, системный шрифт 12 px и боковое меню.
Рабочая область центрирована, ограничена 1360 px и имеет равные внешние отступы. На телефоне
и в горизонтальном положении меню открывается отдельной выдвижной панелью.

Разделы меню по умолчанию закрыты:

- «Рабочее пространство»: состояние и настройки роутера.
- «Управление»: запуск, остановка и перезапуск Remote, Heartbeat, проверка,
  установка Xray, скачивание конфигурации и применение блока из VPS.
- «Настройки»: конфигурация, дизайн и эффекты, переход в службы OpenWrt.

Кнопки запуска, перезапуска, остановки и Xray-настроек доступны также рядом
со статусами. Это существующие действия агента с прежними POST-формами;
кнопка навигации сама по себе не отправляет команды. Все поля UCI и скрытый
ключ доступа сохранены. «Обновить» открывает страницу обычным GET-запросом,
не повторяя последнюю POST-команду. Имя и Router ID экранируются как и раньше.

Обычный, зимний и облегчённый дизайн, эффекты и реакция на курсор используют
существующий runtime и сохранение выбора в браузере. Дополнительный цикл
опроса или анимации не создаётся. В облегчённом режиме эффекты отключены.
Просмотр журнала сохраняет прежние ограничение объёма, скрытие ключей,
тайм-ауты и отмену запросов при закрытии или уходе со страницы.

Оформление применяется только к Remote. LuCI продолжает открывать Remote
через свой существующий переход; остальные приложения OpenWrt не меняются.
Название пункта в «Службах» LuCI — «OWRT Hub»; заголовки панели — «OWRT Hub v125».

«Поддержать разработку» открывает в отдельной вкладке страницу самого Remote
с таким же баннером, как на VPS: текст благодарности, основная и резервная
ссылки, логотипы банков. Прямой переход на сайт доната выполняется только
при нажатии соответствующей ссылки в баннере. Сохраняются выбранный дизайн,
эффекты, ключ доступа и маршрут текущего роутера при открытии через VPS.
Кнопка возврата ведёт в панель этого же роутера.

## Локальная установка

PowerShell Windows 11:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-hub-branding.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Install
```

После успеха обновите страницу Remote через Ctrl+F5. Скрипт устанавливает
CGI, представление и меню LuCI, JavaScript эффектов. Первая резервная копия хранится
в `/root/owrt-remote-backup-before-router-branding-v123` и не перезаписывается
при повторной установке. Перед заменой проверяются версия и синтаксис CGI,
после замены — совпадение содержимого файлов. При неудаче возвращается весь
комплект до текущей попытки. Настройки, агент и Xray не изменяются и не
перезапускаются. Для нового названия в «Службах» очищается только кэш LuCI
и перезапускается rpcd.

## Откат

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Router root@192.168.2.1 -Action Rollback
```

Для локальной подготовки файлов без SSH добавьте `-PrepareOnly`.

## Проверки

- `tests/test_router_sidebar_ui.cjs`: настоящий HTML CGI, навигация, темы,
  формы с ключом/действием, журнал, проксируемый путь, ПК и телефон.
- `tests/test_router_sidebar_deploy.py`: установка, повторная установка,
  откат, неполная копия, восстановление после частичной замены и блокировка.
- `tests/test_router_branding_deploy.py`: тот же набор файлов с меню LuCI,
  сохранение и восстановление меню, очистка кэша и перезапуск только rpcd.
- `tests/test_router_effects.py`: список эффектов и дизайнов, runtime,
  синтаксис shell/JavaScript и включение файлов в установку.

Эти проверки выполняются локально с подставными ответами. Работу после
установки на конкретном роутере нужно проверить отдельно.
