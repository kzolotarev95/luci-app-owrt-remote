# Градиентные имена роутеров

Реализован одобренный макет: голубой → фиолетовый → розовый. На ПК и iOS
оформлены имена в карточках и узлах карты подключений. В Android тот же
градиент применяется в списке, карте, карточке устройства и его инструментах.
Идентификаторы, статусы и кнопки не перекрашиваются. Размеры и шрифт сохранены.

Веб использует отдельный вложенный `span.routerNameGradient`; строки по-прежнему
экранируются, обновление карты меняет `textContent`. Есть fallback для браузера
без background-clip и системного режима высокой контрастности. Градиент
статический и доступен в обычном, зимнем и лёгком оформлении.

Android использует штатный `LinearGradient` в отдельном TextView. Shader
обновляется после изменения имени, размеров или текстовой раскладки, а не
на каждом кадре. Доступность сохраняется: имя не заменяется изображением.

## Установка веб-изменения

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-router-name-gradient.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Откат:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-router-name-gradient-v125`.
Обновляется Hub и согласованный мобильный API; агент роутера не требуется.

APK для телефона: `artifacts/android/OWRT-Hub-Android-0.3.9-v125.apk`.
Сборка локальная; в GitHub, установленные панели и физический телефон
изменения автоматически не отправляются.

## Проверки

- `tests/test_router_name_gradient.cjs`: настоящий дашборд в Chromium и
  WebKit, мобильные ширины до 320 px, длинные и экранированные имена,
  переименование, обновление статусов, фото и три оформления.
- `NativeRedesignInstrumentation -e routerNameOnly true`: цвета на реально
  отрисованных символах, кириллица/RTL/длинные имена, изменение ширины,
  обновление TextView без замены, живые карточки и карточка устройства.
- `assembleDebug`, `assembleDebugAndroidTest`, `lintDebug`.

Локальные результаты 27.11.2026: четыре браузерных сценария прошли
(Chromium 1920/390 px, WebKit 390/320 px). Android 15 прошёл обычный
экран и 320 dp со шрифтом 130%, включая проверку цветов на пикселях,
кириллицу, длинный текст, RTL, изменение ширины и живое обновление карточек.
Lint: 0 ошибок; имеющиеся предупреждения не относятся к оформлению имён.
Подпись APK совпадает с предыдущей локальной сборкой.
