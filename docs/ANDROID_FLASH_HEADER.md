# Android: Flash в одну строку и компактная шапка

Локальная сборка 0.3.10-v125. Панели сохраняют номер v125, изменений сервера нет.

`MainActivity.kv` раньше ограничивал значение Flash общей шириной 110–200 dp.
На узком экране это приводило к переносу при наличии свободного места в строке.
Теперь Flash измеряется по реальной оставшейся ширине после подписи, имеет
одну строку и ограниченный автоподбор текста. Остальные поля не меняются.
Для неожиданно длинного значения остаётся штатное многоточие; реальные
числовые значения проверяются на отсутствие сокращения и переноса.

Назад из приложения теперь вызывается системной кнопкой или жестом Android.
Удалены верхние стрелки в `MainActivity`, `NativeRouterActivity`,
`NativeSettingsActivity`, `NativeBackupActivity` и `BrowserActivity`.
Логика возврата, история WebView и подтверждение закрытия браузера сохранены.
Обычные кнопки «Назад» на экранах ошибок/защиты не являются верхней стрелкой
и остаются доступными.

Удалены строка адреса и её глазок из основной шапки, подпись «Адрес скрыт»
у действия подключения и домен/IP из верхней строки браузера. Явный раздел
настроек «Подключение» продолжает показывать настроенный адрес.
Кнопки просмотра введённого пароля к адресу отношения не имеют и сохранены.

Проверки выполняются только с локальной API-фикстурой и эмулятором:

```powershell
& .\android\build-support\build.ps1 -Tasks @('assembleDebug','assembleDebugAndroidTest','lintDebug','-PnativeRedesign')
& .\.test-output\android-build-tools\sdk\platform-tools\adb.exe -s emulator-5554 shell am instrument -w -e fixtureUrl http://127.0.0.1:8767 -e deviceLayoutOnly true ru.owrthub.app.test/ru.owrthub.app.NativeRedesignInstrumentation
```

Режим проверяет реальную строку Flash, типичные значения свободной/общей
памяти, обновление статусов, отсутствие стрелки/адреса во всех типах шапок,
переходы в инструменты, настройки, резервные копии и встроенный браузер.

APK: `artifacts/android/OWRT-Hub-Android-0.3.10-v125.apk`.
Подпись и SHA256 проверяются перед передачей; установка через файл APK
на телефоне. Для ПК-панели и роутера ничего устанавливать не нужно.

Проверено локально 27.11.2026: Android 15, обычный экран и 320 dp со шрифтом
130%. Пять вариантов Flash, включая большие числа, русские единицы и прочерк,
помещаются целиком в одну строку; живое обновление сохраняет результат.
Проверены все типы верхних панелей и возврат системной кнопкой, включая
подтверждение закрытия встроенного браузера. Сборка и lint успешны,
ошибок lint нет. Подпись APK совпадает с предыдущими локальными сборками.
