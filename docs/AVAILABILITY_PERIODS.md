# Периоды доступности роутеров — локальная v125

В заголовке «Доступность роутеров» вместо одной плашки «24 ч» расположен
переключатель «6 ч / 12 ч / 24 ч» с выделением выбранного периода. Под ним
показано «История за … часов».

Выбор меняет обе линии, заливку, масштаб времени, начальную и среднюю подписи,
текст о покрытии замерами, подсказки мышью/касанием и клавиатурой. Пропуски
замеров остаются пустыми. Используется уже полученная история за 24 часа;
переключение не создаёт дополнительных HTTP-запросов или таймеров.

По умолчанию выбран период 24 ч. Последний выбор сохраняется в localStorage
этого браузера и применяется после F5. При недоступном хранилище переключение
работает до закрытия страницы. Неверное сохранённое значение игнорируется.

Изменены `vps/owrt-remote-hub.py`, источник стилей
`vps/dashboard-vantage.css` и браузерные проверки
`tests/test_hub_sidebar_ui.cjs`. Стили встроены в Python-файл для доставки
одним обновлением Hub. Версия интерфейса остаётся v125.

## Установка в PowerShell Windows 11

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-availability-periods.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
```

Резервная копия: `/root/owrt-remote-backup-before-availability-periods-v125`.
Откат:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

## Локальные проверки

`tests/test_hub_sidebar_ui.cjs`: семь сценариев ПК, мобильного экрана (в том числе
320 px), альбомной ориентации и аккаунтов с разными правами. Проверены все три
периода, реальные точки в выбранном диапазоне, подписи оси, подсказка в середине
периода, сохранение выбора при обновлении данных и F5, отсутствие перекрытия
заголовка переключателем. Снимки блока проверены визуально.

Шесть тестов `tests.test_router_availability` прошли: наблюдения по Heartbeat,
пропуски, перезапуск, ограничение хранения и доступ по правам. Проверены
встроенные стили, синтаксис PowerShell и подготовка установщика без подключения
к VPS. Коммит, push и удалённая установка не выполнялись.
