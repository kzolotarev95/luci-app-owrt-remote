# Мини-графики в верхних блоках VPS-панели

В шести блоках — «Всего роутеров», «В сети», «Не в сети», «Xray запущен»,
«ЦП VPS», «ОЗУ VPS» — добавлены линии с полупрозрачной градиентной заливкой.
Каждый график использует цвет своего показателя. Графики расположены в нижней
части карточек; подписи, значения и кнопка «Подробно» остаются доступны.

## Данные

- Источники: уже существующие успешные ответы `/api/routers` и
  `/api/vps/resources`, а также начальные снимки списка роутеров и ресурсов
  в HTML страницы. ЦП и ОЗУ не ждут первого фонового запроса.
- Отдельные запросы, таймеры, серверные журналы или таблицы БД не добавлены.
- История хранится в памяти текущей вкладки до пяти минут и сохраняется в
  ограниченный `sessionStorage` этой вкладки отдельно для каждого пользователя.
  После F5 восстанавливаются только реальные замеры не старше пяти минут;
  просроченный, повреждённый или слишком большой кэш игнорируется. При запрете
  хранилища графики работают в памяти страницы. Замеры объединяются
  в интервалы по пять секунд, внутри текущего интервала сохраняется последнее
  полученное значение. Память ограничена 120 записями на показатель с учётом
  границ пропусков. Запись выполняется по существующему опросу и при уходе
  со страницы, без отдельного таймера. Данные содержат только время и значения.
- При первом открытии сразу видна ровная линия текущего значения. Это начальное
  отображение одного замера, а не вымышленная история. Затем линия показывает
  накопленную историю; при неизменном значении остаётся ровной. Если сам замер
  недоступен, показана пунктирная линия ожидания. Случайные значения и
  искусственные колебания не используются.
- Счётчики показываются ступенями, ЦП и ОЗУ — линиями между наблюдениями.
  Масштаб подбирается по наблюдаемому диапазону; процентные графики имеют
  минимальный диапазон пять процентных пунктов. Описание для скринридера
  содержит последний замер и наблюдаемые минимум/максимум.
- Ошибки ресурса и паузы между замерами более 15 секунд создают разрывы.
  Неизвестное значение не подменяется нулём; нулевая загрузка ЦП допустима.
- Перерисовка карточек и выбор фильтра не сбрасывают историю и не создают
  новые замеры. Счётчики используют полный доступный пользователю список.

## Локальные проверки

`tests/test_hub_kpi_sparklines.cjs` проверяет реальный HTML Hub на ширинах 320,
390, 1366 и 2560 px: шесть графиков, получение данных из штатных запросов,
фильтрацию, повторную перерисовку, пропуски, нулевое значение, ограничение
истории и отсутствие наложения на подписи. Также проверены начальные линии
при заблокированных запросах, восстановление после F5 и разделение кэша разных
пользователей. Снимки используют тестовые данные.

Также прошли 24 сценария `test_vantage_dashboard.cjs`, четыре ширины
`test_router_model_photos.cjs`, 10 проверок `test_vps_resources.py` и проверка
опроса `test_vps_resources_ui.cjs` (пауза, сеть, тайм-аут, отсутствие параллельных
запросов). Встроенные ресурсы Hub синхронизированы.

## Установка и откат

PowerShell Windows 11, установка текущего локального Hub v125 с накопленными
изменениями и отдельной резервной копией:

```powershell
$Fix = Join-Path $env:USERPROFILE 'Documents\openwrt overlay\vps\deploy-kpi-instant-lines.ps1'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Install
# Откат:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $Fix -Vps root@13.143.167.219 -Action Rollback
```

Резервная копия: `/root/owrt-remote-backup-before-kpi-instant-lines-v125`.
После установки обновите страницу через Ctrl+F5. Линии видны сразу; история
начнёт накапливаться по мере поступления замеров. Роутерный агент обновлять
для графиков не требуется.
