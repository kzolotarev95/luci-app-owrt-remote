# OWRT Hub v125-r3 и Android 0.3.13

## Исправлено обновление VPS с модулями nginx

Устранена ошибка:

```text
Unexpected nginx configuration: /usr/share/nginx/modules-available/mod-http-geoip2.conf
```

Штатные пакеты Ubuntu подключают GeoIP2 и Stream через ссылки из
`/etc/nginx/modules-enabled`, ведущие в `/usr/share/nginx/modules-available`.
Теперь проверка допускает стандартные файлы `mod-*.conf`, если они принадлежат
root, имеют безопасные права и содержат только `load_module` со стандартным
путём к модулю. Эти файлы не перезаписываются.

Произвольные внешние конфиги, небезопасные права и ссылки за пределы разрешённых
путей по-прежнему отклоняются. Проверки nginx, Certbot и SHA256 сохранены;
права на журналы не меняются. Встроенный компонент обслуживания обновлён.

## Изображения устройств

- Friendly NanoPi R3S: фото конкретной модели; поддержаны варианты названия
  Friendly, FriendlyARM и FriendlyElec.
- QEMU Standard PC: отдельная иллюстрация виртуальной машины для строки
  `QEMU Standard PC (i440FX + PIIX, 1996)` и написания `1440FX + PIX`.
- Новые изображения отображаются на карте и в карточках VPS, ПК и iOS.
  Они также включены в Android APK 0.3.13-v125.
- Netis NX62 в этом выпуске не менялся.

## Обновление

В панели VPS нажмите «Обновление панели» или «Повторить обновление».
Для восстановления проблемной установки доступен локальный
`vps/deploy-models-nginx-fix.ps1` с отдельной резервной копией и откатом:
[инструкция](MODELS_NGINX_MODULE_FIX.md).

Надпись в веб-интерфейсе остаётся **v125**, ревизия пакета — **125-r3**.
Предыдущие выпуски v125 и v125-r2 сохранены.

Assets содержат IPK для OpenWrt 23.05/24.10, APK для OpenWrt 25.12 и отдельную
**OWRT-Hub-Android-0.3.13-v125.apk** для телефона. Форматы APK OpenWrt и Android
различаются. Контрольные суммы приложены к выпуску.

## Проверки

- Ubuntu 24.04 VM с настоящими GeoIP2/Stream: прежняя ошибка воспроизведена;
  установка, очистка, откат и обновление отдельным worker завершились успешно.
  Проверены сохранность конфигов модулей, SSL-политики, базы и прав на журналы.
- 20 тестов обслуживания прошли в Linux без пропусков; небезопасные файлы
  и выход ссылок за пределы разрешённых путей отклоняются.
- Chromium 320/390/1366/2560 px и WebKit 390 px: фотографии загружаются,
  сохраняются при обновлении статусов, неизвестные модели используют fallback.
- GitHub Actions собирает пакеты в 30 SDK и перед публикацией проверяет
  установку, переход с опубликованной r2 на r3 и удаление в трёх OpenWrt VM.
