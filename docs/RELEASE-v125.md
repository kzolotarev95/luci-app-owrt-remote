# OWRT Hub v125 и Android 0.3.12

## VPS, ПК и iOS

- Новый компактный дашборд: статистика с сохранением истории мини-графиков,
  доступность за 6/12/24 часа, карта подключений и отдельный баннер диска VPS.
- Блоки карты, доступности, диска и общей статистики можно скрывать;
  выбор сохраняется после перезагрузки страницы. Состояние разделов меню
  также запоминается. Карта раскрывает полный список устройств по кнопке.
- Фото конкретных моделей в карточках и на карте: 88 локальных WebP,
  включая Cudy TR3000/WR3000U, Xiaomi AX3000T и Redmi Router AX6S.
  Изображения сохраняются при обновлении статусов, антенны не обрезаются.
- Общий порядок карточек: стрелки и перетаскивание с сохранением на Hub
  для ПК, iOS и Android. Градиентные имена, компактные значения и кнопки,
  заметки в свёрнутой карточке и подсказка с ID роутера.
- Единые графитовые поверхности, золотые акценты у фото, общая иконка Hub
  и ярко-красный вместо малинового. Зимнее и облегчённое оформление сохранены.
- Исправления мобильной раскладки iOS, сессии после закрытия ярлыка,
  анимации карты и мигания фотографий. На iOS браузер показывает инструкцию
  добавления Hub на домашний экран; вход выполняется из установленного ярлыка.
- В SSH-терминале роутера три настраиваемые быстрые команды. Стандартные
  значения учитывают APK в OpenWrt 25 и opkg в 23/24; команда вставляется
  без автоматического выполнения. В терминале VPS этих слотов нет.
- Исправлено обновление на VPS с Certbot: штатный файл
  `/etc/letsencrypt/options-ssl-nginx.conf` разрешён точным исключением.
  Проверки остальных внешних конфигов nginx и SHA256 сохранены.
- Мобильный API корректно обрабатывает отсутствие Origin у нативного клиента,
  регистр имени хоста и стандартный HTTPS-порт, сохраняя запрет чужого Origin.

## Панель и агент роутера

- Панель получила дашборд в общей палитре и оформление схемы соединения.
- Кнопка проверки и установки обновления с GitHub: проверяются манифест,
  SHA256 и версия; файлы сохраняются в резервную копию, доступен откат.
  Конфигурация UCI, ключи, рабочий Xray и его кэш не заменяются этим обновлением.
- Исправлено определение версии Tachyon по работающему компоненту, включая
  несовпадение с устаревшими метаданными пакета. Состояние и версия передаются
  через Heartbeat.
- Удаление роутера на Hub больше не восстанавливает карточку старым Heartbeat;
  повторно созданная нода не получает прежние данные устройства.

## Android 0.3.12-v125

- Переработан нативный интерфейс в стиле ПК: дашборд, карта подключений,
  фотографии, график доступности и меню с иконками. Компактные блоки и
  выравнивание значений адаптированы для узких экранов.
- Защиту приложения можно включить в настройках: системный PIN, графический
  ключ, пароль или отпечаток. Защита действует при открытии и возвращении
  из фона; отдельный пароль Hub для этого не создаётся.
- Пароль Wake-on-LAN сохраняется после успешной проверки с шифрованием
  Android Keystore и привязкой к Hub, пользователю и роутеру.
- Перестановка карточек синхронизируется через Hub. Flash в состоянии
  устройства отображается одной строкой; из внутренних заголовков убраны
  лишние стрелки и «Адрес скрыт». Системная кнопка «Назад» продолжает работать.
- Фото Redmi Router AX6S и новая красная палитра включены в APK.
  Сохранены существующие настройки Xray, выборочное обновление роутеров,
  заметки с изображениями, терминалы и эффекты.

## Обновление и пакеты

Сначала обновите VPS до v125, затем панель/агент роутера и Android.
IPK предназначены для OpenWrt 23.05/24.10, APK OpenWrt — для 25.12.
Это пакеты `all`/`noarch`; они не содержат бинарник Xray, который подбирает
агент. Android-файл `OWRT-Hub-Android-0.3.12-v125.apk` устанавливается на телефон,
а не на роутер. Суммы SHA256 приложены к релизу.

Старые выпуски остаются доступными для отката. Android подписан прежним
локальным debug-ключом и устанавливается поверх предыдущей APK; это тестовый
выпуск вне Google Play. Системный PIN и физический отпечаток зависят от телефона.
Для Android требуется HTTPS с действующим сертификатом.
